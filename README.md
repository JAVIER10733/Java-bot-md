## 🌟 Introducción

**Java Bot MD** es un bot de WhatsApp Multi-Dispositivo de código abierto, desarrollado con la librería [@whiskeysockets/baileys](https://github.com/WhiskeySockets/Baileys) y diseñado para ofrecer una experiencia de automatización completa, estable y elegante.

### 🎯 ¿Por qué elegir Java Bot MD?

| Característica | Descripción |
|:---|:---|
| 🚀 **Rendimiento** | Optimizado para consumir mínimos recursos y responder en milisegundos |
| 🛡️ **Seguridad** | Sistema anti-baneo, validaciones robustas y manejo seguro de credenciales |
| 🎨 **Interfaz Premium** | Todos los comandos usan diseño de tarjeta con botones CTA oficiales |
|  **Multi-idioma** | Interfaz 100% en español con soporte para múltiples regiones |
| 🔄 **Actualizaciones** | Mantenimiento activo y nuevas funcionalidades cada semana |
| 📱 **Multi-Dispositivo** | Compatible con WhatsApp Web, Android, iOS y Desktop simultáneamente |

## ✨ Características Destacadas

### 🛡️ Sistema de Moderación Inteligente
- **Anti-Link**: Detecta y elimina enlaces no autorizados automáticamente
- **Anti-Badword**: Filtro de palabras ofensivas con 3 niveles de sanción (borrar, advertir, expulsar)
- **Anti-Tag**: Previene el spam de menciones masivas
- **Auto-Kick**: Expulsión automática de usuarios baneados
- **Welcome/Goodbye**: Mensajes de bienvenida y despedida personalizables

###  Descarga de Multimedia
- **YouTube**: Descarga de audio (MP3) y video (MP4) en máxima calidad

- **Instagram**: Reels, posts, stories e IGTV
- **Facebook**: Videos de cualquier calidad
- **Spotify**: Búsqueda y descarga de canciones con metadatos ID3

### 🤖 Inteligencia Artificial
- **ChatGPT Integration**: Respuestas contextuales con memoria de conversación
- **Generación de Imágenes**: Crea imágenes con IA (DALL-E, Flux)
- **Text-to-Video**: Genera videos cortos con modelos de IA
- **Chatbot**: Respuestas automáticas inteligentes para grupos

### 🎨 Creación de Contenido
- **Stickers**: Conversión de imágenes, videos y GIFs a stickers de WhatsApp
- **Text Effects**: 18+ efectos de texto profesionales (neón, hielo, fuego, etc.)
- **Photo Editor**: Blur, removebg, remini, emojimix y más
- **Screenshot Web**: Capturas de pantalla de cualquier sitio web

### 🎮 Juegos y Entretenimiento

## 💻 Instalación Local Detallada

### Requisitos Previos

Antes de comenzar, asegúrate de tener instalados los siguientes componentes:

```bash
✅ Node.js v18.x o superior
✅ Git (para clonar el repositorio)
✅ FFmpeg (para procesamiento de multimedia)
✅ NPM o Yarn (gestor de paquetes)
```

### Instalación en Windows

```powershell
# 1. Abrir PowerShell como administrador e instalar Chocolatey
Set-ExecutionPolicy Bypass -Scope Process -Force
iex ((New-Object System.Net.WebClient).DownloadString('https://community.chocolatey.org/install.ps1'))

# 2. Instalar Node.js y Git
choco install nodejs-lts git ffmpeg -y

# 3. Clonar el repositorio
git clone https://github.com/Java-bot-Md/Java-bot-Md.git
cd Knightbot-MD

# 4. Instalar dependencias
npm install

# 5. Iniciar el bot
node index.js
```

### Instalación en Linux/Ubuntu

```bash
# 1. Actualizar el sistema
sudo apt update && sudo apt upgrade -y

# 2. Instalar Node.js 18.x
curl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash -
sudo apt-get install -y nodejs

# 3. Instalar Git y FFmpeg
sudo apt install git ffmpeg -y

# 4. Clonar el repositorio
git clone https://github.com/TU_USUARIO/Knightbot-MD.git
cd Knightbot-MD

# 5. Instalar dependencias
npm install

# 6. Iniciar el bot
node index.js

# 7. (Opcional) Ejecutar en segundo plano con PM2
npm install -g pm2
pm2 start index.js --name "java-bot"
pm2 save
pm2 startup
```

### Instalación en macOS

```bash
# 1. Instalar Homebrew si no lo tienes
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# 2. Instalar dependencias
brew install node git ffmpeg

# 3. Clonar el repositorio
git clone https://github.com/TU_USUARIO/Knightbot-MD.git
cd Knightbot-MD

# 4. Instalar dependencias de Node
npm install

# 5. Iniciar el bot
node index.js
```

### Instalación con Docker

```bash
# 1. Clonar el repositorio
git clone https://github.com/TU_USUARIO/Knightbot-MD.git
cd Knightbot-MD

# 2. Construir la imagen Docker
docker build -t java-bot-md .

# 3. Ejecutar el contenedor
docker run -d \
  --name java-bot \
  --restart unless-stopped \
  -v ./session:/app/session \
  -v ./data:/app/data \
  java-bot-md

# 4. Ver logs en tiempo real
docker logs -f java-bot
```

## ⚙️ Configuración Avanzada

### Archivo `settings.js`

Configura las variables principales del bot:

```javascript
global.botName = "Java Bot MD";           // Nombre del bot
global.ownerNumber = "593999999999";       // Número del propietario (con código de país)
global.packname = "Java Bot MD";          // Nombre del paquete de stickers
global.author = "Professor";              // Autor de los stickers
global.channelLink = "https://whatsapp.com/channel/...";  // Enlace del canal
global.prefix = ".";                      // Prefijo de comandos
global.mode = "public";                   // 'public' o 'private'
```

### Variables de Entorno (Opcional)

Crea un archivo `.env` en la raíz del proyecto:

```env
TELEGRAM_BOT_TOKEN=your_telegram_bot_token
MAX_RAM_MB=400
NODE_ENV=production
DEBUG=false
```

## 🐛 Solución de Problemas (Troubleshooting)

### Problemas Comunes

<details>
<summary>❌ <b>El bot no responde a los comandos</b></summary>

**Causas posibles:**
- El bot no tiene permisos de administrador en el grupo
- El modo está configurado como `private` y no eres el owner
- El prefijo de comandos es diferente al que estás usando

**Solución:**
```bash
# Verifica el modo en settings.js
global.mode = "public";  # Cambia a 'public' si es necesario

# O usa el comando (solo owner)
.mode public
```
</details>

<details>
<summary>❌ <b>Error al crear stickers: "FFmpeg not found"</b></summary>

**Causa:** FFmpeg no está instalado en el sistema.

**Solución:**
```bash
# Ubuntu/Debian
sudo apt update && sudo apt install ffmpeg -y

# Windows (con Chocolatey)
choco install ffmpeg

# macOS (con Homebrew)
brew install ffmpeg
```
</details>

<details>
<summary> <b>El bot se reinicia constantemente</b></summary>

**Causas posibles:**
- Archivo `creds.json` corrupto
- Memoria RAM insuficiente
- Conflicto de dependencias

**Solución:**
```bash
# 1. Elimina la sesión y vuelve a vincular
rm -rf session/
node index.js

# 2. Aumenta el límite de RAM en settings.js
global.maxStoreMessages = 20;  # Reduce de 50 a 20

# 3. Reinstala dependencias
rm -rf node_modules/
npm install
```
</details>

<details>
<summary>❌ <b>Error "Cannot find module"</b></summary>

**Causa:** Dependencias incompletas o corruptas.

**Solución:**
```bash
# Limpia caché y reinstala
rm -rf node_modules/ package-lock.json
npm cache clean --force
npm install
```
</details>

<details>
<summary>❌ <b>Los comandos de descarga (YouTube, TikTok) fallan</b></summary>

**Causa:** Las APIs externas pueden estar caídas temporalmente.

**Solución:**
- El bot tiene sistema de **fallback en cascada** (intenta múltiples APIs automáticamente)
- Espera unos minutos e intenta de nuevo
- Verifica que el enlace sea válido y público
</details>

## ❓ Preguntas Frecuentes (FAQ)

<details>
<summary><b>¿Es seguro usar este bot?</b></summary>

✅ Sí, el bot utiliza la librería oficial Baileys y no almacena tus mensajes en servidores externos. Sin embargo, **WhatsApp puede detectar el uso de bots no oficiales** y existe un riesgo mínimo de baneo. Usa números secundarios para mayor seguridad.
</details>

<details>
<summary><b>¿Puedo usar el bot en mi número principal?</b></summary>

⚠️ **No es recomendable.** Aunque muchos usuarios lo hacen sin problemas, WhatsApp prohíbe el uso de bots no oficiales en sus Términos de Servicio. Te sugerimos usar un número secundario.
</details>

<details>
<summary><b>¿Cuántos grupos puede manejar el bot simultáneamente?</b></summary>

🚀 El bot puede manejar **cientos de grupos simultáneamente** sin problemas, siempre que el servidor tenga suficientes recursos (mínimo 512MB RAM recomendado).
</details>

<details>
<summary><b>¿Cómo actualizo el bot a la última versión?</b></summary>

```bash
# Si instalaste con Git
git pull origin main
npm install

# Si usas un panel de hosting, simplemente reinicia el bot
```
</details>

# 3. Crea una rama para tu funcionalidad
git checkout -b feature/mi-nueva-funcion

# 4. Realiza tus cambios y haz commit
git add .
git commit -m "✨ Añade: descripción de la nueva función"

# 5. Sube los cambios

# 6. Abre un Pull Request en GitHub
